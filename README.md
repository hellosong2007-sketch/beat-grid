# กล่องจังหวะ

ตารางสร้างจังหวะกลอง เวลาไหลไปตามช่อง (หนึ่งจังหวะมีสี่ช่อง) แต่ละแถวคือเสียงกลองหนึ่งชนิด ช่องที่เติมสีคือช่องที่มีเสียง

ฝึกให้เชื่อมสามอย่างเข้าด้วยกัน คือ **เสียงของจังหวะ วิธีนับ (1 · 2และ · 3) และตำแหน่งในห้องเพลง**

## วิธีเปิด

ดับเบิลคลิก `index.html` เปิดด้วย Chrome หรือ Edge ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต
เปิดบนมือถือได้เหมือนกัน (บนจอแคบ เวลาไหลลงล่าง บนจอกว้างเวลาไหลไปทางขวา)

## โหมดเล่น

| โหมด | เล่นอย่างไร |
|---|---|
| สร้างเอง | วางจังหวะของตัวเอง กดฟัง ดูวิธีนับใต้ตาราง เลือกจังหวะตัวอย่างมาลองได้ สลับ 4/4 และ 3/4 ได้ จังหวะที่สร้างจะถูกเก็บไว้ |
| ฟังแล้วเรียง | ฟังจังหวะโจทย์ (ไม่เห็นว่าช่องไหน) แล้ววางให้เหมือน กดตรวจ (ต้องใช้เสียง) |
| อ่านแล้วเรียง | อ่านวิธีนับ เช่น "กลองใหญ่: 1 · 3 · 3และ" แล้ววางลงตารางโดยยังไม่ได้ฟัง |

ในโหมดโจทย์ ตรวจผ่านในครั้งแรกติดกันหลายข้อจะได้คะแนนพิเศษ ตรวจไม่ผ่านจะเห็นช่องที่ **เกิน** และ **ขาด** ถ้าติดจริง ๆ กด "ดูเฉลย" ได้
(ข้อนั้นได้ 0 คะแนน) ผ่านแล้วจะเห็นการ์ดบอกชื่อจังหวะ ว่าอะไรทำให้เป็นจังหวะนั้น และวิธีนับของทุกแถว

## วิธีนับ

หนึ่งจังหวะแบ่งเป็นสี่ช่อง อ่านว่า **เลขจังหวะ · อี · และ · อะ** เช่น ช่องที่ 6 (ช่องที่สามของจังหวะที่ 2) อ่านว่า "2และ"

## ไฟล์เดียว ห้าโซน

ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว ในส่วน `<script>` แบ่งเป็นห้าโซน ค้นหาด้วยคำว่า "โซน A" ถึง "โซน E"

| โซน | มีอะไร | แก้ได้ไหม |
|---|---|---|
| A · ข้อมูล | แถวเสียง (`TRACKS`) จังหวะ (`GROOVES`) ระดับ โหมด เหรียญ และข้อความภาษาไทยทั้งหมด (`TEXT`) | แก้ได้ |
| B · ตั้งค่า | ตัวเลขของเกม เช่น ความเร็ว จำนวนข้อ คะแนน (`CONFIG`) | แก้ได้ |
| C · แกนเกม | ตัวคิดของเกม เช่น เทียบตาราง นับจังหวะ คิดคะแนน | **ห้ามแก้** |
| D · หน้าจอและเสียง | วาดตาราง เล่นเสียงกลอง เก็บสถิติ ปุ่มตรวจระบบ | ห้ามแก้ถ้าไม่จำเป็น |
| E · ส่วนเสริม | ว่างไว้ให้เขียนความสามารถใหม่ | เขียนที่นี่ |

หน้าตาแก้ได้ที่ส่วน `<style>` ด้านบนของไฟล์ ทุกสีและขนาดเป็นตัวแปร CSS ที่มีคำอธิบายภาษาไทยกำกับ
(กลุ่ม "สีหลัก" "ขนาดและระยะ" และ "สีของเกม") สีของแต่ละแถวเสียงคือ `--track-hat` `--track-snare` `--track-wood` `--track-kick`

### เพิ่มแถวเสียงที่ห้า

เพิ่มหนึ่งบรรทัดในตาราง `TRACKS` (โซน A) และเพิ่มตัวแปรสีหนึ่งตัวใน `<style>` แถวใหม่จะโผล่ในตาราง ส่งเสียง เก็บ และโหลดกลับเอง

```js
{ id: 'cow', label: 'โคเบลล์', kind: 'tone', hz: 660, decaySec: 0.1, colorVar: '--track-cow' }
```

`kind` มี 3 แบบ `'kick'` (เสียงทุ้มไหลลง ใช้ `hz` กับ `endHz`) `'noise'` (เสียงซ่า ใช้ `filterHz`) และ `'tone'` (เสียงเคาะ ใช้ `hz`)

### เพิ่มจังหวะของตัวเอง

เพิ่มหนึ่งบล็อกในตาราง `GROOVES` แต่ละแถวเขียนเป็นข้อความ `x` คือมีเสียง `.` คือว่าง ความยาวต้องเท่ากับ จำนวนจังหวะ × 4

```js
{
  id: 'mine',
  name: 'ชื่อจังหวะ',
  about: 'หนึ่งประโยคบอกว่าอะไรทำให้เป็นจังหวะนี้',
  beats: 4,
  bpm: 100,
  level: 1,
  rows: { kick: 'x...x...x...x...', hat: '..x...x...x...x.' }
}
```

จังหวะใหม่จะอยู่ในรายการตัวอย่าง และถูกสุ่มออกเป็นโจทย์ในระดับนั้นเอง ถ้าเขียนผิด จังหวะนั้นจะถูกข้ามและปุ่ม **ตรวจระบบ** จะบอกว่าผิดตรงไหน

## ตัวช่วยสำหรับโซน E

เหตุการณ์ที่ฟังได้ด้วย `Game.on('ชื่อเหตุการณ์', function (detail) { ... })`

| เหตุการณ์ | `detail` |
|---|---|
| `screenChange` | `{ from, to }` |
| `gameStart` | `{ mode, level, rounds }` |
| `cellToggle` | `{ trackId, step, on }` |
| `playStart` | `{ source, bpm, beats }` (`source` คือ `'mine'` หรือ `'target'`) |
| `stepTick` | `{ step, beat, isBeatStart, hits }` ทุกช่องที่เล่น (`hits` คือรหัสแถวที่มีเสียง) |
| `loopEnd` | `{ loops }` ทุกครั้งที่เล่นผ่านช่องสุดท้ายของห้อง |
| `playStop` | `{ source }` |
| `roundStart` | `{ index, grooveId, mode }` |
| `roundCheck` | `{ perfect, missing, extra, failedChecks }` (จำนวน ไม่ใช่รายการ) |
| `roundEnd` | `{ grooveId, points, failedChecks, revealed }` |
| `scoreChange` | `{ score, delta, streak }` |
| `badgeEarned` | `{ id, name }` |
| `gameEnd` | `{ mode, level, score, stars, rounds: [{ grooveId, failedChecks, revealed }] }` |

ตัวช่วยที่เรียกได้

| ตัวช่วย | ทำอะไร |
|---|---|
| `Game.getGrid()` | สำเนาตารางตอนนี้ `{ beats, rows: { รหัสแถว: [true หรือ false ต่อช่อง] } }` |
| `Game.setGrid(grid)` | ใส่ตารางใหม่ (ใช้ได้ในโหมดสร้างเองเท่านั้น) คืน `true` ถ้าใส่ได้ |
| `Game.setBpm(n)` | ตั้งความเร็ว (ในช่วง 60 ถึง 160 โหมดสร้างเองเท่านั้น) |
| `Game.play()` / `Game.stop()` / `Game.isPlaying()` | เล่น หยุด ถามว่ากำลังเล่นหรือไม่ |
| `Game.playHit(trackId, whenSec)` | เล่นเสียงกลองหนึ่งแถว |
| `Game.showToast('ข้อความ')` | แสดงข้อความสั้น ๆ |
| `Game.getState()` / `Game.getStats()` | ดูสถานะตอนนี้ / สถิติที่เก็บไว้ (อ่านอย่างเดียว) |
| `Game.Core` | ฟังก์ชันของโซน C เช่น `Core.countingText(row, 4, COUNT_SYLLABLES)` |

ช่องว่างที่วางปุ่มหรือข้อความได้ (เป็น `div` ว่างในหน้า ใช้ `document.getElementById('...')`)
`slotHome` หน้าแรก · `slotHud` แถบคะแนน · `slotActions` ในแถบปุ่มด้านล่าง · `slotPanel` ใต้ตาราง · `slotResult` หน้าสรุป

ถ้าส่วนเสริมที่เขียนมีข้อผิดพลาด เกมจะเล่นต่อได้ และข้อความผิดพลาดจะไปแสดงที่ปุ่ม **ตรวจระบบ**

## เมนู feature สำหรับการสอบ

เลือกอย่างน้อย 2 อย่าง (หรือคิดเองแล้วเขียนไว้ใน spec) ข้อ 3 และ 4 เป็นข้อที่ง่ายที่สุด

1. **สุ่มจังหวะ** ปุ่มในโหมดสร้างเอง เติมตารางด้วยจังหวะสุ่มที่ฟังเข้าท่า (ใช้ `Game.getGrid` `Game.setGrid`)
2. **ช่องเก็บจังหวะ** ช่องเก็บจังหวะสามช่อง เก็บด้วยที่เก็บข้อมูลของตัวเอง (ใช้ `Game.getGrid` `Game.setGrid`)
3. **เสียงของฉัน** เพิ่มแถวเสียงที่ห้าใน `TRACKS` พร้อมค่าเสียงและสีของตัวเอง
4. **จังหวะของฉัน** เพิ่มจังหวะสองอันใน `GROOVES` มีชื่อและประโยค `about`
5. **เร่งทีละน้อย** สวิตช์ฝึกในโหมดสร้างเอง ทุกสี่ห้องเพิ่มความเร็วทีละ 4 (ใช้ `loopEnd` `Game.setBpm`)
6. **ไฟนับจังหวะ** ไฟดวงหนึ่งใน `slotHud` กะพริบทุกจังหวะ และกะพริบต่างออกไปที่จังหวะที่ 1 (ใช้ `stepTick`)
7. **คัดลอกจังหวะเป็นข้อความ** ปุ่มที่คัดลอกจังหวะเป็นข้อความวิธีนับ

## ตรวจระบบ

หลังแก้ไฟล์ทุกครั้ง เปิดเกม กด **ตั้งค่า → ตรวจระบบ** ต้องขึ้นว่า "ผ่าน 15 จาก 15 ข้อ"
ถ้าไม่ผ่าน แปลว่าส่วนที่ห้ามแก้ (โซน C) เสียหาย ให้ย้อนกลับไปไฟล์ที่ commit ล่าสุด
หรือเปิดไฟล์ด้วย `?selfcheck=1` ต่อท้ายที่อยู่ (เช่น `index.html?selfcheck=1`) เพื่อให้ตรวจเองตอนเปิดหน้า
ถ้าจังหวะที่เพิ่มเองเขียนผิด ปุ่มตรวจระบบจะบอกว่าจังหวะไหนถูกข้ามเพราะอะไร
